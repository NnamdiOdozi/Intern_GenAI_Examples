# Revision QA

- Render the complete source and revised decks with the same tool and settings.
- Compare all slide images; only approved slide positions should differ.
- Inspect each changed slide at full size.
- Check text fit, crop, hyperlink, notes, source blocks, footer text, and object alignment.
- Run the presentations overflow test.
- Run `audit_pptx.py` with required and forbidden phrases.
- Confirm slide and note counts match expectations.
- Remove scratch renders and inspection sidecars from the deliverable folder.

A successful package audit does not replace visual review. A visually clean render does not replace hyperlink and notes inspection. Use both.
