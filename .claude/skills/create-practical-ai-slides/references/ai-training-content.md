# AI training content checklist

Use this as a selection checklist, not a mandatory syllabus. Include only concepts needed for the stated learning outcome.

## Foundations

- Define artificial intelligence, machine learning, and generative AI.
- Contrast discriminative and generative models with familiar examples.
- Explain tokens, next-token prediction, probability distributions, sampling, and why fluency is not verification.
- Connect neural networks, matrix operations, transformer blocks, and attention without teaching every internal component.
- Explain the common training pipeline: pre-training, supervised fine-tuning, and reinforcement learning. State that exact recipes vary.

## Models and economics

- Distinguish small, medium, and large models with current examples when useful.
- Contrast instant and reasoning models.
- Distinguish proprietary, open-weight, and open-source models carefully.
- Explain quality, cost, latency, subscriptions, APIs, and batch processing.

## Systems

- Distinguish an LLM from a complete chat product.
- Explain APIs in plain language.
- Show that model calls are stateless and apparent memory comes from supplied or retrieved context.
- Explain finite context windows, caching, compaction, and context management.
- Define embeddings as dense vectors that encode useful relationships.
- Explain vector databases, retrieval-augmented generation, agentic RAG, tools, integrations, and MCP only to the level required.

## Practice

- Include code generation, learning, document review, meeting minutes, research, administrative work, reporting, and domain-specific professional applications.
- Separate assistance from autonomous decision-making.
- Encourage controlled experimentation, documentation, and professional judgement.

## Risk and governance

- Cover hallucination using realistic modern examples.
- Explain direct and indirect prompt injection and the dangerous combination of untrusted content, tool access, and sensitive credentials or actions.
- Cover privacy, security, logging, interpretability, human oversight, and applicable regulation.
- Distinguish what a control prevents, detects, or mitigates.

## Accuracy rules

Verify current model names, prices, regulations, incidents, and organisation-specific claims. Do not treat an illustrative probability as measured output. Label hypothetical system diagrams as speculative. Use the strongest available primary source in speaker notes.
